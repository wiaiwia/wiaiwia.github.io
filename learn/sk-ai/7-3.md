### 7월 16일

#### AI Literacy

1. **생성형 AI의 컨텍스트 윈도우**
   - 작업 기억의 한계 때문에 가장 앞부분과 가장 끝부분의 내용이 컨텍스트에 많이 담긴다.
   - 길어지면 핵심을 요약해 새 대화로 옮기는 것이 좋다.

2. **LLM을 넘어선 AI Agent**
   - 목표가 주어지면 스스로 **계획(Planning) → 도구 사용(Tool Use) → 실행 → 검증**을 수행
   - 대표 도구: `Codex`, `Claude Code`
   - **Single Agent vs Multi Agent**
     - Multi Agent는 `Orchestrator`가 역할을 분담
     - 모두가 공유하는 지속 메모리(Shared Memory)가 있고, 상황을 보며 일을 쪼개고 다시 나눈다.
   - **Agency** : 역할의 크기, 얼마나 스스로 하는가의 정도

3. **World Model**
   - Video AI에 물리 엔진을 입혀 실제 세계를 시뮬레이션하는 모델
   - 대표 사례: Google `Genie`, NVIDIA `Cosmos`

4. **기능별 LLM**

   | 도구 | 특징 |
   | :--- | :--- |
   | `NotebookLM` | 내가 올린 자료에서만 근거로 답변 (RAG) |
   | `Perplexity` | 웹 검색 기반 답변할 수 있는 기능, 출처 제공 |
   | `Liner Scholar` | 학술 논문에서만 검색하여 답변할 수 있음 |

5. **Few-shot Prompting**
   - 프롬프트에 패턴과 예시를 보여주며 원하는 출력을 유도하는 기법

#### Codex

1. 터미널에서 실행 가능

2. **`AGENTS.md`**
   - 프로젝트 루트에 `AGENTS.md` 파일에 지침을 적을 수 있음 (웹 기반의 System Prompt 역할)
   - 실무에서는 Andrej Karpathy의 작업 원칙을 넣음:
     - `Think before coding`
     - `Simplicity first`
     - `Surgical changes` = 요청과 직접 관련된 코드만 건드리기
     - `Goal-driven execution`

3. **MCP (Model Context Protocol)**
   - AI Agent가 외부 도구나 데이터에 연결하는 표준 프로토콜
   - Codex는 하나의 `MCP Client`

4. **Skill**
   - 검증된 작업 절차, 노하우를 에이전트에게 가르치는 재사용 가능한 지침 묶음
   - 상황에 따른 Workflow를 찾아 수행하도록 함
   - `MCP가 도구(Tool)` 라면, `Skill은 방법(How-to)`

5. **Playwright MCP**
   - 에이전트가 브라우저를 직접 조작할 수 있게 함
   - 이동, 클릭, 입력, 폼 제출, 스냅샷 등
   - 화면 이미지가 아닌 DOM 코드베이스에 접근

6. **Vercel**
   - 만든 웹 앱을 온라인으로 배포
   - MCP의 일종으로 원격(HTTP) + OAuth 서버 방식

7. **Context7 MCP**
   - `Next.js`, `Supabase` 등 각종 라이브러리/프레임워크의 최신 공식 문서와 예제 코드를 가져와 컨텍스트에 삽입
   - 오래된 학습 데이터로 인한 **환각(Hallucination) 방지**

8. **Superpowers**
   - 스킬 프레임워크
   - 브레인스토밍, 체계적 디버깅, TDD(Test Driven Development), 계획 작성 같은 검증된 Workflow를 Skill로 묶음
   - 작업에 맞게 자동으로 에이전트를 이끌어줌
